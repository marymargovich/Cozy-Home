# PROJECT SPECIFICATION: «COZY SOUND ROOM» — V2

## 1. PROJECT OVERVIEW

- **Project Name:** Cozy Sound Room
- **Engine:** Unity
- **Visual Format:** fixed painterly 2D audio-diorama; not true mathematical isometric
- **Genre:** Interactive Audio-Diorama / Lo-Fi Music Sandbox
- **Core Philosophy:** a tactile, low-stress room where the player creates musical Lo-Fi mixes by toggling living interior objects. The player character remains off-screen.

---

## 2. CURRENT VISUAL BASELINE

The current approved master room reference is the stable composition baseline for future room-state work.

### Fixed camera

**fixed painterly 2D diorama camera, 3/4 corner view, slightly elevated viewpoint**

The camera is static. Do not use mouse-follow camera, room parallax, floating room layers, or continuous camera motion.

### Approved room composition

- spacious residential attic;
- warm mineral-plaster walls;
- aged light-oak / soft ash-oak floor;
- restrained exposed beams;
- partial fireplace at the **left** frame edge;
- one broad sage-green armchair in the left-center, seat clear and readable;
- one small wooden side table beside it, top clear;
- one medium-height book cabinet right of center;
- several separate floating wall shelves with breathing space;
- one large wide multi-pane window on the **right** wall with a deep usable windowsill;
- central floor remains relatively open;
- base image uses soft neutral daylight and does not bake in season, weather, or strong time of day.

The room may be revisited later only if testing with full interactive/seasonal dressing shows that the base composition is not strong enough.

---

## 3. CORE ARCHITECTURAL PILLARS

### A. Procedural Environment Generator (PEG)

#### 1. Time-of-Day & Season System

Reads the local system calendar and clock (`System.DateTime.Now`).

Time states:
- `Morning` — 06:00–11:00
- `Day` — 11:00–17:00
- `Evening` — 17:00–22:00
- `Night` — 22:00–06:00

Season states:
- `Spring`
- `Summer`
- `Autumn`
- `Winter`

Time of day and season are separate systems. The base room is not permanently tied to a rainy evening or amber lighting preset.

#### 2. Weather Generator (RNG)

Generated by random seed on startup; no manual player switching.

States:
- `Clear`
- `Light Rain`
- `Heavy Downpour`
- `Thunderstorm`
- `Snowfall`
- `Blizzard`
- `Hail`

Weather controls window/exterior effects, weather particles, ambient sound beds, and related atmospheric parameters. Weather is independent from time of day and should be filtered by season only where the project logic explicitly requires it.

### B. Room Scene Architecture & Spawn Layers

#### 1. Static Master Room Layer

Permanent architecture/furniture:
- walls;
- wooden floor;
- sloped ceiling and beams;
- large multi-pane window and deep windowsill;
- partial fireplace architecture;
- one armchair;
- one small side table;
- one main book cabinet;
- separate open shelves.

No sofa. No work desk. No office/studio identity.

#### 2. Deterministic Seasonal Layer

Seasonal decoration is an overlay on the same master room. It never creates four separate rooms and never changes the camera or permanent furniture placement.

Examples:
- `Spring`: light textile, blossom/willow branch, young greenery, light window fabric.
- `Summer`: woven mat/light rug, wildflowers/berries, lighter textile, airy window layer.
- `Autumn`: plaid/woven blanket on armchair, terracotta/rust accents, maple/rowan, small pumpkin.
- `Winter`: chunky knit textile, soft rug, pine/cones/cinnamon, restrained winter greenery, frost detail.

#### 3. Dynamic Interactive Layer / Spawn System

Interactive props do **not** have one fixed location.

The room uses typed spawn points/surfaces. Current surface categories:
- `floor`
- `table / horizontal surface`
- `wide shelf`
- `narrow shelf`
- `windowsill`
- `armchair / soft surface`
- `wall`
- `window hanging`
- `ceiling / suspended`

Each asset has its own allowed surface set.

Examples:
- `Cat`: armchair + floor + table + wide windowsill
- `Tea Cup`: table + windowsill + suitable shelf
- `Dreamcatcher`: wall
- `Wall Clock`: wall
- `Wind Chimes`: window / suspended

On each session start, the system selects exactly **80% of the interactive prop pool** and places them on valid available spawn points.

### C. Multi-Track Audio Engine & Export

- **DSP Synchronization:** all audio stems start synchronously at `volume = 0` via master timer (`AudioSettings.dspTime`).
- **Tempo / Key:** strict 75 BPM and matching key across musical stems.
- **Interaction:** click toggles smooth Fade In / Fade Out and linked animation state.
- **Audio-Reactive Lighting:** internal atmosphere-only objects such as garland/candle may sample audio levels/bass.
- **Audio Recording & Export:** record the `AudioListener` stream in real time, buffer PCM data, save `.wav`.

## 4. INTERACTIVE ASSET MATRIX

### A. Sound-Producing Props

1. `Cat` — bass purring track. Allowed surfaces: armchair / floor / table / wide windowsill. Double click: stretches, claws, sleepy mrow.
2. `Tea Cup with Spoon` — ceramic/metal percussion. Double click: steam forms note/heart.
3. `Fireplace` — crackling wood + low rumble. Double click: spark burst.
4. `Open Book` — page rustle. Double click: rapid page fan + glowing paper butterfly.
5. `Creaky Floorboard` — low wooden creak/downbeat. Double click: mouse/spider peek.
6. `Aquarium with Light` — filter hum + bubbling.
7. `Knitting Basket` — rhythmic wooden needle clicking.
8. `Wind Chimes` — harmonic chime; window/suspended.
9. `Dreamcatcher` — feather/bead flutter; wall.
10. `Crystal Chandelier` — subtle high chime + caustic light; ceiling/suspended.
11. `Wall Clock with Pendulum` — muffled ticking; wall.
12. `Vintage Vinyl Player` — vinyl crackle + melodic Lo-Fi loop; dynamic asset, not baked into master room.

### B. Atmosphere-Only Objects

1. `String Garland` — audio-reactive light pulse.
2. `Table Candle` — organic flicker reacting to bass.
3. `Window Curtains` — wind sway changing interior shadow shapes.

---

## 5. SPLASH / ENTRY FLOW

The entry screen uses a separate layered composition:

1. **Door background:** natural aged wooden door in Cozy Sound Room visual language.
2. **Interactive keyhole/lock:** brass-trimmed keyhole, visually dominant enough to act as the entry interaction.
3. **Game title:** separate transparent `COZY SOUND ROOM` lettering asset; do not bake it into the door generation.
4. **Entry action:** lock/keyhole click initializes WebGL/Mobile audio context and proceeds into the room.

The door is believable and tactile, not medieval, not fantasy architecture, and not a generic game portal.

## 6. UI & NAVIGATION

- `Custom Cursor`: vintage handcrafted wand; hover state adds subtle glow/micro-sparks.
- `Control Bar`: REC/Stop, Export WAV, Reset/Clear All, Play All, Screenshot Mode, Info/Help, Master Volume.
